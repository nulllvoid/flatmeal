FINALFlatMeal — shared cart, end to end

Voting is gone. The flat wakes up to an empty cart and a ranked set of suggestions; whoever gets there first says who's eating and picks a main course, and accompaniments and sides are suggested around it. Anyone can edit it live until it locks. Quantities default to the headcount and follow it. Max mains is a soft guardrail set during onboarding — skippable, and it warns rather than blocks. Seventeen screens, in the order a flatmate meets them.
